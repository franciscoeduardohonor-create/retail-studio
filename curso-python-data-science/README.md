## 🗂️ Estructura del Curso

### 📦 MÓDULO 1: Fundamentos de Python
**Duración estimada: 1-2 semanas**

Aprende las bases de Python necesarias para Data Science.

```
modulo1-fundamentos/
├── 01_variables_y_tipos.py          # Variables, tipos de datos, operaciones
├── 02_estructuras_datos.py          # Listas, tuplas, diccionarios, sets
└── 03_funciones_control_flujo.py    # Funciones, if/else, loops
```

**Temas cubiertos:**
- Variables y tipos de datos
- Estructuras de datos (listas, tuplas, diccionarios, sets)
- Control de flujo (if/elif/else, for, while)
- Funciones y parámetros
- Comprehensions
- Manejo de errores

---

### 🔢 MÓDULO 2: NumPy - Computación Numérica
**Duración estimada: 1 semana**

Domina NumPy, la base de todo el ecosistema científico de Python.

```
modulo2-numpy/
├── 01_introduccion_numpy.py         # Arrays, creación, propiedades
└── 02_operaciones_arrays.py         # Indexación, operaciones, estadísticas
```

**Temas cubiertos:**
- Creación de arrays (zeros, ones, arange, random, etc.)
- Propiedades de arrays (shape, dtype, size)
- Indexación y slicing
- Operaciones vectorizadas
- Broadcasting
- Funciones matemáticas y estadísticas
- Álgebra lineal básica

**Ventajas de NumPy:**
- ⚡ Hasta 100x más rápido que listas de Python
- 💾 Usa menos memoria
- 🎯 Operaciones optimizadas
- 🔬 Base de pandas, matplotlib, scikit-learn

---

### 🐼 MÓDULO 3: Pandas - Análisis de Datos
**Duración estimada: 2-3 semanas**

Pandas es LA herramienta para análisis de datos en Python.

```
modulo3-pandas/
├── 01_introduccion_pandas.py        # Series, DataFrames, exploración
└── 02_limpieza_datos.py             # Limpieza, transformación, groupby
```

**Temas cubiertos:**
- Series y DataFrames
- Lectura de datos (CSV, Excel, etc.)
- Exploración de datos (head, info, describe)
- Selección y filtrado
- Datos faltantes (NaN)
- Duplicados
- Transformación de datos
- GroupBy y agregaciones
- Merge, join, concat
- Pivot tables

**Casos de uso:**
- 📊 Análisis exploratorio
- 🧹 Limpieza de datos
- 📈 Reportes y dashboards
- 🔄 ETL (Extract, Transform, Load)

---

### 📊 MÓDULO 4: Visualización de Datos
**Duración estimada: 1-2 semanas**

Crea visualizaciones profesionales para comunicar insights.

```
modulo4-visualizacion/
├── 01_matplotlib_basico.py          # Gráficas básicas con Matplotlib
└── 02_seaborn_estadistico.py        # Visualizaciones avanzadas con Seaborn
```

**Temas cubiertos:**

**Matplotlib:**
- Gráficas de líneas
- Barras (verticales, horizontales, agrupadas, apiladas)
- Histogramas
- Scatter plots
- Pie charts
- Subplots
- Personalización completa

**Seaborn:**
- Distribuciones (histplot, kdeplot)
- Categóricas (boxplot, violinplot, barplot)
- Relaciones (scatterplot, regplot)
- Heatmaps y correlaciones
- Pairplots
- FacetGrid

**Visualizaciones incluidas:**
- ✅ 30+ ejemplos de gráficas
- ✅ Código completamente comentado
- ✅ Todas las imágenes guardadas

---

### 🤖 MÓDULO 5: Machine Learning con Scikit-Learn
**Duración estimada: 2-3 semanas**

Aprende los fundamentos de Machine Learning aplicado.

```
modulo5-machine-learning/
├── 01_regresion.py                  # Regresión lineal, Ridge, Lasso
└── 02_clasificacion.py              # Logística, Árboles, Random Forest
```

**Temas cubiertos:**

**Regresión:**
- Regresión Lineal Simple
- Regresión Lineal Múltiple
- Regularización (Ridge, Lasso)
- Validación cruzada
- Métricas (R², RMSE, MAE)

**Clasificación:**
- Regresión Logística
- Árboles de Decisión
- Random Forest
- Matriz de confusión
- Métricas (Accuracy, Precision, Recall, F1)

**Flujo de trabajo ML:**
1. Preparar datos
2. Dividir train/test
3. Entrenar modelo
4. Evaluar
5. Optimizar
6. Predecir

---

### 🚀 MÓDULO 6: Proyectos Avanzados Integrados
**Duración estimada: 2-4 semanas**

- Mejores prácticas de la industria

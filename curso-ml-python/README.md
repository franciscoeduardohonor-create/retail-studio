# 🤖 Curso Completo de Machine Learning con Python
## De Principiante a Avanzado

¡Bienvenido al curso más completo de Machine Learning con Python! Este curso te llevará desde los fundamentos hasta técnicas avanzadas de Deep Learning.

## 📚 Estructura del Curso

### **Nivel Principiante**

#### **Módulo 1: Fundamentos de Python y NumPy**
- Introducción a Python para ML
- Arrays y operaciones con NumPy
- Broadcasting y vectorización
- Ejercicios prácticos

#### **Módulo 2: Pandas y Análisis de Datos**
- DataFrames y Series
- Limpieza y preprocesamiento de datos
- Análisis exploratorio de datos (EDA)
- Manejo de datos faltantes

#### **Módulo 3: Visualización de Datos**
- Matplotlib básico y avanzado
- Seaborn para visualizaciones estadísticas
- Gráficos interactivos
- Mejores prácticas de visualización

### **Nivel Intermedio**

#### **Módulo 4: Regresión Lineal**
- Teoría de regresión lineal
- Implementación desde cero
- Usando scikit-learn
- Evaluación de modelos
- Proyecto: Predicción de precios de casas

#### **Módulo 5: Clasificación y Regresión Logística**
- Regresión logística
- Métricas de clasificación
- Validación cruzada
- Proyecto: Detección de spam

#### **Módulo 6: Árboles de Decisión y Random Forests**
- Árboles de decisión
- Random Forests
- Feature importance
- Proyecto: Predicción de abandono de clientes

#### **Módulo 7: SVM y KNN**
- Support Vector Machines
- K-Nearest Neighbors
- Optimización de hiperparámetros
- Proyecto: Clasificación de imágenes

### **Nivel Avanzado**

#### **Módulo 8: Clustering**
- K-Means
- DBSCAN
- Hierarchical Clustering
- Proyecto: Segmentación de clientes

#### **Módulo 9: Redes Neuronales Básicas**
- Perceptrón desde cero
- Backpropagation
- Introducción a TensorFlow/Keras
- Proyecto: Clasificación MNIST

#### **Módulo 10: Deep Learning Avanzado**
- Redes Neuronales Convolucionales (CNN)
- Redes Neuronales Recurrentes (RNN/LSTM)
- Transfer Learning
- Proyecto: Clasificador de imágenes avanzado

## 📖 Cómo usar este curso

1. **Sigue el orden**: Los módulos están diseñados para construirse uno sobre otro
2. **Practica activamente**: Cada módulo tiene ejercicios para que los hagas
3. **Experimenta**: Modifica los ejemplos y observa qué sucede
4. **Proyectos**: Completa todos los proyectos prácticos

## 🎯 Objetivos de Aprendizaje

Al finalizar este curso serás capaz de:
- ✅ Entender los fundamentos matemáticos del ML
- ✅ Implementar algoritmos desde cero
- ✅ Usar librerías profesionales (scikit-learn, TensorFlow)
- ✅ Preprocesar y analizar datos reales
- ✅ Evaluar y optimizar modelos
- ✅ Construir proyectos completos de ML
- ✅ Crear redes neuronales profundas

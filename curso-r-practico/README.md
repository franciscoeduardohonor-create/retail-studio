# 📊 Curso Práctico de R con RStudio
## De Principiante a Avanzado

Bienvenido al curso completo de R y RStudio. Este curso está diseñado para llevarte desde los conceptos más básicos hasta técnicas avanzadas de programación y análisis de datos.

---

## 🎯 Objetivos del Curso

Al finalizar este curso serás capaz de:
- ✅ Programar en R con confianza
- ✅ Manipular y transformar datos eficientemente
- ✅ Crear visualizaciones profesionales
- ✅ Realizar análisis estadísticos
- ✅ Aplicar técnicas avanzadas de programación
- ✅ Resolver problemas reales con R

## 🚀 Cómo Usar Este Curso

### 1️⃣ Instalación de R y RStudio

**Descargar R:**
- Visita: https://cran.r-project.org/
- Descarga la versión para tu sistema operativo
- Instala siguiendo las instrucciones

**Descargar RStudio:**
- Visita: https://posit.co/download/rstudio-desktop/
- Descarga RStudio Desktop (versión gratuita)
- Instala después de haber instalado R

### 2️⃣ Configuración Inicial

Abre RStudio y ejecuta:
```r
# Instalar paquetes necesarios para el curso
install.packages("ggplot2")
install.packages("dplyr")
install.packages("tidyr")
install.packages("readr")
install.packages("purrr")
install.packages("magrittr")
```

### 3️⃣ Metodología de Estudio

**Para cada módulo:**

1. **LEE** el archivo principal del módulo (ej: `01-introduccion.R`)
   - Ejecuta cada línea de código
   - Lee los comentarios explicativos
   - Experimenta modificando los valores

2. **PRACTICA** con los ejemplos
   - Los ejemplos son casos reales
   - Modifica los datos con tus propios valores
   - Observa cómo cambian los resultados

3. **RESUELVE** los ejercicios
   - Intenta resolverlos sin ver las soluciones
   - Si te atascas, revisa la teoría
   - Compara con las soluciones al terminar

4. **CREA** tus propios proyectos
   - Aplica lo aprendido a tus datos
   - Combina conceptos de diferentes módulos

## 💡 Consejos para el Aprendizaje

### ✅ DO (Haz esto)
- ✔️ Escribe el código tú mismo, no copies y pegues
- ✔️ Experimenta modificando los ejemplos
- ✔️ Practica todos los días, aunque sea 30 minutos

- ✔️ Usa la ayuda: `?función` o `help(función)`

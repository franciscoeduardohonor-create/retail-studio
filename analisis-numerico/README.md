# 📐 Curso Completo de Análisis Numérico
## De Principiante a Avanzado

Bienvenido al curso práctico de Análisis Numérico. Este curso está diseñado para llevarte desde los conceptos básicos hasta técnicas avanzadas, con implementaciones en C++ y Python.

## 🎯 Objetivos del Curso

- Entender los fundamentos del análisis numérico y el error computacional
- Implementar algoritmos numéricos desde cero
- Aplicar métodos numéricos a problemas reales
- Desarrollar intuición sobre la precisión y eficiencia de los métodos

## 📚 Estructura del Curso

### 📖 Nivel Principiante

#### **Módulo 1: Introducción y Errores Numéricos**
- Representación de números en computadora
- Error de redondeo y truncamiento
- Propagación de errores
- Estabilidad numérica
- [📂 Ir al módulo](./modulo-01-errores/)

#### **Módulo 2: Solución de Ecuaciones No Lineales**
- Método de Bisección
- Método de Newton-Raphson
- Método de la Secante
- Método de Punto Fijo
- [📂 Ir al módulo](./modulo-02-ecuaciones-no-lineales/)

#### **Módulo 3: Sistemas de Ecuaciones Lineales**
- Eliminación Gaussiana
- Método de Gauss-Jordan
- Factorización LU
- Métodos iterativos (Jacobi, Gauss-Seidel)
- [📂 Ir al módulo](./modulo-03-sistemas-lineales/)

### 📚 Nivel Intermedio

#### **Módulo 4: Interpolación**
- Interpolación de Lagrange
- Diferencias divididas de Newton
- Interpolación de Hermite
- Splines cúbicos
- [📂 Ir al módulo](./modulo-04-interpolacion/)

#### **Módulo 5: Aproximación de Funciones**
- Mínimos cuadrados lineales
- Mínimos cuadrados no lineales
- Aproximación polinomial
- Ortogonalización de Gram-Schmidt
- [📂 Ir al módulo](./modulo-05-aproximacion/)

#### **Módulo 6: Diferenciación Numérica**
- Diferencias finitas (adelante, atrás, centradas)
- Fórmulas de alta precisión
- Extrapolación de Richardson
- [📂 Ir al módulo](./modulo-06-diferenciacion/)

### 🚀 Nivel Avanzado

#### **Módulo 7: Integración Numérica**
- Regla del Trapecio
- Regla de Simpson
- Cuadratura de Gauss
- Integración adaptativa
- Integrales impropias
- [📂 Ir al módulo](./modulo-07-integracion/)

#### **Módulo 8: Ecuaciones Diferenciales Ordinarias (EDOs)**
- Método de Euler
- Métodos de Runge-Kutta (RK2, RK4)
- Métodos multipaso
- Sistemas de EDOs
- Problemas de valores en la frontera
- [📂 Ir al módulo](./modulo-08-edos/)

#### **Módulo 9: Temas Avanzados**
- Eigenvalores y eigenvectores
- Método QR
- Ecuaciones Diferenciales Parciales (EDPs)
- Método de diferencias finitas para EDPs
- Transformada Rápida de Fourier (FFT)
- [📂 Ir al módulo](./modulo-09-avanzado/)

## 🛠️ Requisitos

### Software Necesario
- **C++**: Compilador g++ o clang++ (C++11 o superior)
- **Python**: Python 3.7+ con NumPy, SciPy, Matplotlib
- Editor de código (VS Code, CLion, PyCharm, etc.)

### Conocimientos Previos
- Programación básica en C++ o Python
- Cálculo diferencial e integral
- Álgebra lineal básica

## 🚀 Cómo Usar Este Curso

1. **Lee la teoría** en el README de cada módulo
2. **Estudia los ejemplos** de código comentado
3. **Ejecuta los programas** y experimenta con los parámetros
4. **Resuelve los ejercicios** propuestos
5. **Compara tus soluciones** con las proporcionadas

## 📝 Estructura de Cada Módulo

Cada módulo contiene:
- **README.md**: Teoría, explicaciones y ejemplos matemáticos
- **ejemplos_cpp/**: Implementaciones en C++ comentadas
- **ejemplos_python/**: Implementaciones en Python comentadas
- **ejercicios/**: Problemas propuestos
- **soluciones/**: Soluciones detalladas

## 💡 Consejos para el Aprendizaje

1. **Practica escribiendo el código tú mismo**: No solo copies y pegues
2. **Experimenta**: Cambia parámetros, prueba diferentes funciones
3. **Visualiza**: Usa gráficas para entender el comportamiento
4. **Compara**: Implementa el mismo método en C++ y Python
5. **Verifica**: Compara tus resultados con soluciones analíticas cuando sea posible

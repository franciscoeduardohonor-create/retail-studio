## 👥 ¿Para quién es este curso?

Este curso es perfecto para ti si:

- ✅ Nunca has usado Git y quieres aprenderlo desde cero
- ✅ Usas Git básicamente pero quieres dominar técnicas avanzadas
- ✅ Trabajas en equipo y necesitas entender colaboración con Git
- ✅ Quieres contribuir a proyectos open source
- ✅ Buscas mejorar tu flujo de trabajo con Git

**No necesitas experiencia previa**, empezamos desde cero.

---

## 🎯 ¿Qué aprenderás?

Al finalizar este curso, podrás:

### Nivel Principiante
- ✅ Instalar y configurar Git
- ✅ Crear repositorios y hacer commits
- ✅ Entender el flujo de trabajo básico de Git
- ✅ Ignorar archivos con .gitignore
- ✅ Deshacer cambios de forma segura

### Nivel Intermedio
- ✅ Crear y fusionar ramas (branches)
- ✅ Resolver conflictos de merge
- ✅ Trabajar con repositorios remotos (GitHub, GitLab)
- ✅ Colaborar en equipo efectivamente
- ✅ Hacer fork y pull requests

### Nivel Avanzado
- ✅ Usar git rebase para limpiar historial
- ✅ Aplicar commits selectivamente con cherry-pick
- ✅ Guardar trabajo temporal con stash
- ✅ Encontrar bugs con git bisect
- ✅ Implementar workflows profesionales

## 📚 Estructura del Curso

El curso está dividido en **4 módulos principales** con lecciones progresivas:

### 📘 Módulo 1: Fundamentos de Git (Principiante)

**Duración estimada: 3-4 horas**

1. [Introducción y Configuración](modulo-01-fundamentos/01-introduccion-y-configuracion.md)
   - ¿Qué es Git?
   - Instalación en diferentes sistemas
   - Configuración inicial (nombre, email)
   - Configuraciones útiles

2. [Tu Primer Repositorio](modulo-01-fundamentos/02-primer-repositorio.md)
   - Crear repositorio con `git init`
   - Estados de archivos en Git
   - Hacer tu primer commit
   - Ver historial con `git log`

3. [Ignorar Archivos (.gitignore)](modulo-01-fundamentos/03-ignorar-archivos-gitignore.md)
   - ¿Por qué ignorar archivos?
   - Sintaxis de .gitignore
   - Plantillas para diferentes lenguajes
   - Archivos ya rastreados

4. [Deshacer Cambios](modulo-01-fundamentos/04-deshacer-cambios.md)
   - `git restore`: Descartar cambios
   - `git commit --amend`: Modificar commits
   - `git reset`: Volver atrás (--soft, --mixed, --hard)
   - `git revert`: Deshacer sin reescribir historial

---

### 📗 Módulo 2: Trabajo con Ramas (Intermedio)

**Duración estimada: 3-4 horas**

1. [Crear y Cambiar Ramas](modulo-02-ramas/01-crear-y-cambiar-ramas.md)
   - ¿Qué son las ramas?
   - Crear ramas con `git branch` y `git switch`
   - Cambiar entre ramas
   - Eliminar ramas
   - Convenciones de nombres

2. [Fusionar Ramas (Merge)](modulo-02-ramas/02-fusionar-ramas-merge.md)
   - Fast-forward merge
   - Three-way merge
   - Estrategias de merge
   - Ver ramas fusionadas

3. [Resolver Conflictos](modulo-02-ramas/03-resolver-conflictos.md)
   - ¿Por qué ocurren conflictos?
   - Identificar y resolver conflictos
   - Herramientas de merge
   - Abortar un merge
   - Prevenir conflictos

---

### 📙 Módulo 3: Colaboración y Trabajo Remoto (Intermedio-Avanzado)

**Duración estimada: 4-5 horas**

1. [Repositorios Remotos](modulo-03-colaboracion/01-repositorios-remotos.md)
   - ¿Qué son los remotos?
   - Conectar con GitHub/GitLab
   - Clonar repositorios
   - Push y Pull
   - Autenticación SSH
   - Gestionar remotos

2. [Colaboración en Equipo](modulo-03-colaboracion/02-colaboracion-en-equipo.md)
   - Workflows de colaboración
   - Fork y Pull Requests
   - Code Review
   - Estrategias de branching
   - Protected branches
   - Mejores prácticas

---

### 📕 Módulo 4: Técnicas Avanzadas (Avanzado)

**Duración estimada: 4-5 horas**

1. [Git Rebase](modulo-04-avanzado/01-rebase.md)
   - ¿Qué es rebase?
   - Merge vs Rebase
   - Rebase interactivo
   - Limpiar historial
   - Reglas de oro del rebase

2. [Stash, Cherry-Pick y Bisect](modulo-04-avanzado/02-stash-cherry-pick-bisect.md)
   - Git Stash: Guardar cambios temporalmente
   - Cherry-Pick: Aplicar commits específicos
   - Bisect: Encontrar bugs con búsqueda binaria
   - Casos de uso prácticos

## 💻 Requisitos previos

### Software necesario:

1. **Git** instalado en tu sistema
   - Windows: [https://git-scm.com/download/win](https://git-scm.com/download/win)
   - macOS: `brew install git`
   - Linux: `sudo apt install git`

2. **Editor de texto** (elige uno):
   - VS Code (recomendado): [https://code.visualstudio.com/](https://code.visualstudio.com/)
   - Sublime Text
   - Atom
   - Vim/Nano

3. **Terminal/Línea de comandos**
   - Windows: Git Bash, PowerShell, o CMD
   - macOS: Terminal
   - Linux: Terminal

### Conocimientos previos:

- ✅ Uso básico de la terminal (cd, ls, mkdir)
- ✅ Crear y editar archivos de texto
- ❌ NO necesitas saber programación
- ❌ NO necesitas experiencia con Git

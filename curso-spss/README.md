# 📊 Curso Práctico de SPSS - De Principiante a Avanzado

¡Bienvenido al curso completo de SPSS! Este curso te llevará desde los conceptos básicos hasta técnicas avanzadas de análisis estadístico.

## 🎯 Objetivos del Curso

- Dominar la interfaz y sintaxis de SPSS
- Realizar análisis estadísticos descriptivos e inferenciales
- Crear visualizaciones profesionales
- Aplicar técnicas avanzadas de análisis multivariante
- Interpretar resultados estadísticos correctamente

## 📚 Estructura del Curso

### Módulo 1: Introducción y Conceptos Básicos
- Interfaz de SPSS
- Tipos de datos y variables
- Importación y exportación de datos
- Manipulación básica de datos
- **Duración estimada:** 2-3 horas

### Módulo 2: Estadística Descriptiva
- Medidas de tendencia central
- Medidas de dispersión
- Tablas de frecuencias
- Estadísticos por grupos
- **Duración estimada:** 3-4 horas

### Módulo 3: Gráficos y Visualizaciones
- Histogramas y diagramas de caja
- Gráficos de barras y sectores
- Gráficos de dispersión
- Personalización avanzada
- **Duración estimada:** 2-3 horas

### Módulo 4: Pruebas de Hipótesis
- Conceptos fundamentales
- Pruebas t (una muestra, muestras independientes, muestras relacionadas)
- Pruebas no paramétricas
- Chi-cuadrado
- **Duración estimada:** 4-5 horas

### Módulo 5: Correlación y Regresión
- Correlación de Pearson y Spearman
- Regresión lineal simple
- Regresión lineal múltiple
- Diagnóstico de regresión
- **Duración estimada:** 4-5 horas

### Módulo 6: ANOVA y Comparaciones Múltiples
- ANOVA de un factor
- ANOVA factorial
- ANOVA de medidas repetidas
- Pruebas post-hoc
- **Duración estimada:** 4-5 horas

### Módulo 7: Técnicas Avanzadas
- Análisis factorial
- Análisis de confiabilidad
- Regresión logística
- Análisis de supervivencia
- Análisis de series temporales
- **Duración estimada:** 6-8 horas

## 🚀 Cómo Usar Este Curso

1. **Lee el contenido teórico** en cada módulo
2. **Estudia los ejemplos** de sintaxis comentados
3. **Practica con los datasets** proporcionados
4. **Realiza los ejercicios** al final de cada módulo
5. **Compara tus resultados** con las soluciones

## 💡 Requisitos Previos

- SPSS Statistics instalado (versión 20 o superior recomendada)
- Conocimientos básicos de estadística (deseable pero no obligatorio)
- Ganas de aprender 😊

## 📖 Recursos Adicionales

- Ejemplos prácticos con datos reales
- Interpretación detallada de resultados
- Ejercicios con soluciones paso a paso

## 🎓 Certificación

Al completar todos los módulos y ejercicios, habrás adquirido habilidades para:
- Realizar análisis estadísticos completos
- Interpretar resultados profesionalmente
- Automatizar análisis mediante sintaxis
- Generar reportes estadísticos de calidad

## 💡 Consejos Antes de Empezar

### Cómo Acceder al Editor de VBA en Excel:
1. Presiona `Alt + F11` (Windows) o `Fn + Alt + F11` (Mac)
2. O ve a Desarrollador > Visual Basic

### Si no ves la pestaña Desarrollador:
1. Archivo > Opciones > Personalizar cinta de opciones
2. Marca la casilla "Desarrollador"

### Para ejecutar un macro:
- Presiona `F5` en el editor de VBA
- O ve a Desarrollador > Macros > Selecciona el macro > Ejecutar

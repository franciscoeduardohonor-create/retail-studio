# 🚀 Curso Práctico de TensorFlow: De Principiante a Avanzado

¡Bienvenido al curso más completo de TensorFlow en español! Este curso te llevará desde los conceptos básicos hasta técnicas avanzadas de Deep Learning.

## 📚 Índice del Curso

### 📌 Módulo 1: Fundamentos de TensorFlow
**Nivel: Principiante**
- Introducción a TensorFlow y su ecosistema
- Tensores: creación y operaciones básicas
- Variables y constantes
- Operaciones matemáticas
- Grafos computacionales
- **Proyectos prácticos:**
  - Calculadora con tensores
  - Análisis de datos con TensorFlow

### 📌 Módulo 2: Redes Neuronales Básicas
**Nivel: Principiante-Intermedio**
- Regresión lineal con TensorFlow
- Regresión logística
- Perceptrón simple
- Redes neuronales densas (Dense layers)
- Funciones de activación
- Optimizadores y funciones de pérdida
- **Proyectos prácticos:**
  - Predicción de precios de casas
  - Clasificación de dígitos MNIST
  - Clasificación de flores Iris

### 📌 Módulo 3: Redes Neuronales Convolucionales (CNN)
**Nivel: Intermedio**
- Capas convolucionales
- Pooling layers
- Arquitecturas CNN clásicas
- Data augmentation
- Regularización (Dropout, Batch Normalization)
- **Proyectos prácticos:**
  - Clasificación de imágenes CIFAR-10
  - Reconocimiento de dígitos escritos a mano
  - Detector de gatos vs perros
  - Clasificación de ropa (Fashion MNIST)

### 📌 Módulo 4: Redes Neuronales Recurrentes (RNN/LSTM)
**Nivel: Intermedio-Avanzado**
- RNN básicas
- LSTM y GRU
- Secuencias de tiempo
- Text processing
- Word embeddings
- **Proyectos prácticos:**
  - Predicción de series temporales
  - Análisis de sentimientos
  - Generador de texto
  - Predicción de precios de acciones

### 📌 Módulo 5: Transfer Learning y Modelos Preentrenados
**Nivel: Avanzado**
- Transfer Learning: conceptos y aplicaciones
- Fine-tuning de modelos
- Modelos preentrenados (VGG, ResNet, MobileNet, EfficientNet)
- Feature extraction
- **Proyectos prácticos:**
  - Clasificador de imágenes personalizado
  - Detector de objetos
  - Clasificación de imágenes médicas

### 📌 Módulo 6: Proyectos Avanzados
**Nivel: Avanzado**
- GANs (Generative Adversarial Networks)
- Autoencoders
- Modelos de atención y Transformers
- TensorFlow Serving y deployment
- Optimización de modelos
- **Proyectos prácticos:**
  - Generador de imágenes con GAN
  - Sistema de recomendación
  - Chatbot con LSTM
  - API de predicción en producción

## 🛠️ Instalación y Configuración

### Requisitos previos
- Python 3.8 o superior
- pip o conda

### Instalación

```bash
# Crear entorno virtual (recomendado)
python -m venv tensorflow-env

# Activar entorno virtual
# En Windows:
tensorflow-env\Scripts\activate
# En Linux/Mac:
source tensorflow-env/bin/activate

# Instalar dependencias
pip install -r requirements.txt
```

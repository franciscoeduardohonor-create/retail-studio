# 📘 Curso Completo de COBOL - De Principiante a Avanzado

Bienvenido al curso más completo de COBOL en español. Este curso te llevará desde los conceptos básicos hasta técnicas avanzadas, con ejemplos prácticos y ejercicios en cada módulo.

## 🎯 Objetivos del Curso

- Dominar la sintaxis y estructura de COBOL
- Comprender el manejo de archivos secuenciales e indexados
- Aprender a trabajar con bases de datos DB2
- Desarrollar aplicaciones empresariales completas
- Entender el código legacy en entornos mainframe

## 📚 Estructura del Curso

### Nivel Principiante (01-principiante)
1. **Módulo 1: Fundamentos de COBOL**
   - Historia y relevancia
   - Estructura básica de un programa
   - Divisiones IDENTIFICATION, ENVIRONMENT, DATA, PROCEDURE
   - Primer programa: "Hola Mundo"

2. **Módulo 2: Estructuras de Control y Datos**
   - Variables y tipos de datos
   - Operaciones aritméticas
   - Estructuras IF, EVALUATE
   - Bucles PERFORM

### Nivel Intermedio (02-intermedio)

3. **Módulo 3: Manejo de Archivos**
   - Archivos secuenciales
   - Archivos indexados (VSAM)
   - Operaciones CRUD
   - Validación de datos

4. **Módulo 4: Tablas y Arreglos**
   - Definición de tablas
   - OCCURS y REDEFINES
   - Búsqueda y ordenamiento
   - Tablas multidimensionales

5. **Módulo 5: Subprogramas y Modularización**
   - CALL y CANCEL
   - Paso de parámetros
   - COPY y bibliotecas
   - Mejores prácticas

### Nivel Avanzado (03-avanzado)

6. **Módulo 6: COBOL con Bases de Datos**
   - Embedded SQL
   - DB2 y COBOL
   - Cursores y transacciones
   - Manejo de errores SQLCODE

7. **Módulo 7: Proyecto Final Integrador**
   - Sistema bancario completo
   - Gestión de inventarios
   - Generación de reportes

## 🛠️ Requisitos

- Compilador COBOL (GnuCOBOL recomendado)
- Editor de texto
- Terminal/línea de comandos
- Ganas de aprender

## 📖 Cómo Usar Este Curso

1. **Lee la teoría** en cada archivo .md
2. **Estudia los ejemplos** comentados en archivos .cob
3. **Practica** con los ejercicios propuestos
4. **Compila y ejecuta** cada ejemplo
5. **Experimenta** modificando el código

## 🚀 Instalación de GnuCOBOL

### Linux (Debian/Ubuntu)
```bash
sudo apt-get update
sudo apt-get install gnucobol
```

### Linux (RHEL/CentOS)
```bash
sudo yum install gnucobol
```

### macOS
```bash
brew install gnucobol
```

### Windows
Descarga desde: https://gnucobol.sourceforge.io/

## ✍️ Compilar y Ejecutar

```bash
# Compilar
cobc -x -free programa.cob

# Ejecutar
./programa
```

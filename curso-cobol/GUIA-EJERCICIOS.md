# 📝 Guía de Ejercicios y Práctica

## 🎯 Cómo Usar Esta Guía

Esta guía contiene ejercicios progresivos para reforzar cada módulo del curso. Resuélvelos en orden para obtener el máximo beneficio.

## 📚 Nivel Principiante

### Módulo 1: Fundamentos

**Ejercicio 1.1: Tarjeta de Presentación**
- Crea un programa que muestre tu tarjeta de presentación
- Incluye: nombre, profesión, email, teléfono
- Usa formato decorativo con bordes

**Ejercicio 1.2: Calculadora de Propinas**
- Pide el monto de la cuenta
- Calcula propinas al 10%, 15% y 20%
- Muestra el total con cada propina

**Ejercicio 1.3: Conversor de Unidades**
- Convierte kilómetros a millas
- Convierte Celsius a Fahrenheit
- Convierte pesos a dólares

### Módulo 2: Estructuras de Control

**Ejercicio 2.1: Clasificador de Edad**
```
0-12: Niño
13-17: Adolescente
18-64: Adulto
65+: Adulto Mayor
```

**Ejercicio 2.2: Calculadora de IMC**
- Pide peso (kg) y altura (m)
- Calcula IMC = peso / (altura²)
- Clasifica: Bajo peso, Normal, Sobrepeso, Obesidad

**Ejercicio 2.3: Juego de Adivinanzas**
- Programa "piensa" un número del 1-100
- Usuario tiene 7 intentos
- Da pistas: "mayor" o "menor"

**Ejercicio 2.4: Calculadora de Nómina**
- Pide salario base
- Calcula:
  - ISR (según tablas)
  - IMSS (2.5%)
  - Retiro (1.125%)
- Muestra salario neto

## 📊 Nivel Intermedio

### Módulo 3: Archivos

**Ejercicio 3.1: Agenda Telefónica**
- Archivo indexado con contactos
- CRUD completo
- Buscar por nombre o teléfono

**Ejercicio 3.2: Sistema de Biblioteca**
- Archivo de libros (código, título, autor, disponible)
- Registrar préstamos
- Buscar libros
- Reporte de libros prestados

**Ejercicio 3.3: Control de Gastos**
- Archivo secuencial de gastos diarios
- Categorías (comida, transporte, etc.)
- Reporte mensual por categoría
- Total y promedio diario

### Módulo 4: Tablas

**Ejercicio 4.1: Registro de Temperaturas**
- Tabla de temperaturas (7 días × 4 semanas)
- Temperatura promedio por día
- Día más caluroso/frío
- Reporte semanal

**Ejercicio 4.2: Gestión de Productos**
- Tabla de 50 productos
- Código, nombre, stock, precio
- Buscar producto
- Listar productos con bajo stock

**Ejercicio 4.3: Tabla de Multiplicar Interactiva**
- Genera tabla NxN (usuario elige N)
- Permite buscar resultado
- Muestra tabla formateada

### Módulo 5: Subprogramas

**Ejercicio 5.1: Biblioteca de Validaciones**
Crea subprogramas para validar:
- RFC (formato correcto)
- CURP
- Email
- Teléfono
- Código postal

**Ejercicio 5.2: Utilidades Matemáticas**
Subprogramas para:
- Factorial
- Número primo
- MCD (máximo común divisor)
- MCM (mínimo común múltiplo)
- Potencia

**Ejercicio 5.3: Formateadores**
- Formatear fechas (DD/MM/YYYY, MM-DD-YY, etc.)
- Formatear moneda
- Formatear nombres (capitalize)
- Formatear teléfonos

# 📚 Recursos y Referencias COBOL

## 🛠️ Herramientas de Desarrollo

### Compiladores

**GnuCOBOL (Recomendado)**
- **Gratuito y open source**
- Compatible con COBOL-85, COBOL-2002, COBOL-2014
- Funciona en Linux, Windows, macOS
- Instalación:
  ```bash
  # Ubuntu/Debian
  sudo apt-get install gnucobol

  # macOS
  brew install gnucobol

  # Windows
  # Descargar de https://gnucobol.sourceforge.io/
  ```

**Micro Focus COBOL**
- Versión comercial profesional
- Visual COBOL para desarrollo moderno
- Integración con .NET y Java

**IBM Enterprise COBOL**
- Para mainframes z/OS
- El estándar en grandes corporaciones

### IDEs y Editores

**VSCode**
- Extensión: "COBOL Language Support"
- Syntax highlighting
- IntelliSense básico
- Configuración:
  ```json
  {
    "cobol.format": "fixed",
    "cobol.margin": 72
  }
  ```

**OpenCOBOLIDE**
- IDE dedicado para COBOL
- Integra GnuCOBOL
- Gratuito
- https://github.com/OpenCobolIDE/OpenCobolIDE

**Eclipse con COBOL Plugin**
- Para desarrollo empresarial
- Integración con herramientas IBM

## 📝 Notas Finales

### Consejos para Aprender COBOL

1. **Practica diariamente** - Aunque sea 30 minutos
2. **Lee código real** - Busca proyectos open source
3. **Haz proyectos completos** - No solo ejercicios pequeños
4. **Entiende el contexto** - COBOL es para procesamiento de datos
5. **Aprende mainframe** - Si quieres trabajar en bancos/gobierno
6. **Moderniza** - Aprende también integración con sistemas nuevos

# 🎓 Proyectos Finales - Curso de FORTRAN

¡Felicidades por llegar hasta aquí! Estos proyectos integran todo lo que has aprendido.

## 📋 Lista de Proyectos

### 1. **Sistema de Gestión de Estudiantes** ⭐⭐
Aplicación completa para administrar estudiantes, calificaciones y generar reportes.
- Tipos derivados
- Archivos
- Funciones y subrutinas
- Arreglos dinámicos

### 2. **Calculadora Científica** ⭐⭐
Calculadora interactiva con múltiples funciones matemáticas y científicas.
- Menús interactivos
- Funciones matemáticas
- Manejo de errores

### 3. **Simulador de Física** ⭐⭐⭐
Simula movimiento de proyectiles con visualización en archivo.
- Métodos numéricos
- Integración
- Archivos de salida

### 4. **Análisis de Datos Estadísticos** ⭐⭐⭐
Programa que lee datos de archivos CSV y genera estadísticas completas.
- Lectura de archivos
- Cálculos estadísticos
- Generación de reportes

### 5. **Juego de Vida (Conway)** ⭐⭐⭐⭐
Implementación del famoso autómata celular.
- Arreglos 2D
- Algoritmos
- Animación en terminal

## 🚀 Cómo usar los proyectos

1. Lee el código cuidadosamente
2. Compila y ejecuta cada proyecto
3. Experimenta modificando parámetros
4. Intenta agregar nuevas funcionalidades
5. Crea tus propias variaciones

## 💡 Desafíos adicionales

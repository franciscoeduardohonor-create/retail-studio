# 🚀 Curso Práctico de FORTRAN - De Principiante a Avanzado

¡Bienvenido al curso completo de FORTRAN! Este curso está diseñado para llevarte desde cero hasta un nivel avanzado en programación FORTRAN, con énfasis en ejemplos prácticos y aplicaciones del mundo real.

## 📚 Estructura del Curso

### **Nivel Principiante**
- **Módulo 1**: Fundamentos de FORTRAN
- **Módulo 2**: Estructuras de Control y Arreglos

### **Nivel Intermedio**
- **Módulo 3**: Subrutinas y Funciones
- **Módulo 4**: Archivos y Entrada/Salida
- **Módulo 5**: Módulos y Programación Modular

### **Nivel Avanzado**
- **Módulo 6**: Tipos Derivados y POO
- **Módulo 7**: Programación Numérica Avanzada
- **Proyectos Finales**: Aplicaciones Reales

## 🎯 ¿Qué aprenderás?

- ✅ Sintaxis y estructura básica de FORTRAN
- ✅ Tipos de datos, variables y operadores
- ✅ Estructuras de control (IF, DO, SELECT)
- ✅ Arreglos y matrices multidimensionales
- ✅ Funciones y subrutinas
- ✅ Manejo de archivos
- ✅ Programación modular
- ✅ Tipos derivados y orientación a objetos
- ✅ Cálculo numérico y científico
- ✅ Optimización de código

## 🛠️ Requisitos

- Compilador de FORTRAN (se recomienda gfortran)
- Editor de texto o IDE
- Conocimientos básicos de programación (útil pero no obligatorio)

## 📖 Cómo usar este curso

1. Empieza por el Módulo 1 y avanza secuencialmente
2. Lee los archivos `.f90` con ejemplos comentados
3. Ejecuta cada ejemplo y experimenta con modificaciones
4. Completa los ejercicios propuestos
5. Revisa las soluciones después de intentar por tu cuenta

## 💻 Compilar y ejecutar programas FORTRAN

```bash
# Compilar un programa
gfortran -o programa programa.f90

# Ejecutar el programa
./programa
```

## 🌟 Consejos para el éxito

- Practica diariamente con los ejemplos
- No pases al siguiente módulo sin dominar el actual
- Experimenta modificando los códigos
- Escribe tus propias versiones de los ejercicios
- Documenta tu código con comentarios

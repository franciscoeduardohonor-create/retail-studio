# 📊 Curso Práctico de Power BI: De Principiante a Avanzado

## 🎯 Bienvenido al Curso Completo de Código para Power BI

Este curso está diseñado para llevarte desde cero hasta un nivel avanzado en el manejo de código para Power BI. Aprenderás los dos lenguajes fundamentales:

- **Power Query M**: Para transformación y limpieza de datos (ETL)
- **DAX (Data Analysis Expressions)**: Para análisis y cálculos avanzados

## 📚 Estructura del Curso

### 🟢 Nivel Principiante

#### Módulo 1: Power Query M - Fundamentos
- Introducción a Power Query
- Sintaxis básica del lenguaje M
- Importación y conexión de datos
- Transformaciones básicas
- Tipos de datos
- **[Ir al Módulo 1](./modulo-1-power-query-basico/README.md)**

#### Módulo 4: DAX - Fundamentos
- ¿Qué es DAX y para qué sirve?
- Sintaxis básica
- Medidas vs Columnas Calculadas
- Funciones básicas de agregación
- Contexto de fila y filtro (introducción)
- **[Ir al Módulo 4](./modulo-4-dax-basico/README.md)**

---

### 🟡 Nivel Intermedio

#### Módulo 2: Power Query M - Intermedio
- Funciones personalizadas
- Manejo de errores

- Tablas dinámicas y unpivot
- Parámetros y consultas dinámicas
- **[Ir al Módulo 2](./modulo-2-power-query-intermedio/README.md)**

#### Módulo 5: DAX - Intermedio
- Time Intelligence (inteligencia temporal)
- Funciones CALCULATE y FILTER
- Relaciones y contexto avanzado

- **[Ir al Módulo 5](./modulo-5-dax-intermedio/README.md)**

#### Módulo 6: DAX - Avanzado
- Patrones DAX avanzados

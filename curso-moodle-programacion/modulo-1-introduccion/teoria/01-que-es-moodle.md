# Módulo 1: Introducción a la Programación en Moodle

## 1.1 ¿Qué es Moodle?

### Conceptos Fundamentales

**Moodle** (Modular Object-Oriented Dynamic Learning Environment) es un sistema de gestión de aprendizaje (LMS) de código abierto utilizado en todo el mundo para crear y gestionar cursos en línea.

#### Características principales:
- **Código abierto**: Desarrollado en PHP, puedes modificarlo libremente
- **Modular**: Funciona con plugins que extienden su funcionalidad
- **Orientado a objetos**: Utiliza programación orientada a objetos (POO)
- **Base de datos**: Usa MySQL, PostgreSQL, MariaDB u otras

### Arquitectura de Moodle

```
Moodle/
├── admin/          # Administración del sitio
├── auth/           # Plugins de autenticación
├── blocks/         # Bloques (widgets laterales)
├── course/         # Gestión de cursos
├── mod/            # Módulos de actividad (foros, tareas, etc.)
├── theme/          # Temas visuales
├── lib/            # Bibliotecas principales
├── lang/           # Archivos de idioma
└── config.php      # Configuración principal
```

### ¿Por qué programar en Moodle?

1. **Personalización**: Adaptar Moodle a necesidades específicas
2. **Automatización**: Crear procesos automáticos
3. **Integración**: Conectar con otros sistemas
4. **Innovación**: Desarrollar nuevas funcionalidades educativas

### Tecnologías que necesitas conocer

- **PHP**: Lenguaje principal de Moodle
- **JavaScript/jQuery**: Para interactividad
- **HTML/CSS**: Para la presentación
- **SQL**: Para base de datos
- **Git**: Para control de versiones

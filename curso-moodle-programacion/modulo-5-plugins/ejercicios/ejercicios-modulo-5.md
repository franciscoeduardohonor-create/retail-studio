# Ejercicios Prácticos - Módulo 5: Creación de Plugins

## Ejercicio 1: Plugin Local "Notes"
**Nivel: Intermedio**

Crear un plugin para tomar notas personales.

**Requisitos:**
- CRUD completo de notas
- Categorías de notas
- Búsqueda por texto
- Favoritos
- Exportar a PDF

## Ejercicio 2: Block Plugin "Quick Links"
**Nivel: Intermedio**

Crear un bloque con links personalizados.

**Requisitos:**
- Admin puede configurar links globales
- Usuarios pueden agregar links personales
- Drag & drop para ordenar
- Iconos personalizados

## Ejercicio 3: Plugin de Autenticación "Custom Auth"
**Nivel: Avanzado**

Crear autenticación personalizada.

**Requisitos:**
- Login con email en lugar de username
- Integración con API externa
- Sincronización de usuarios
- Mapeo de roles

## Ejercicio 4: Module Activity "Quiz Pro"
**Nivel: Avanzado**

Crear módulo de actividad mejorado.

**Requisitos:**
- Múltiples tipos de preguntas
- Calificación automática
- Reportes detallados
- Límite de tiempo

## Ejercicio 5: Theme Plugin
**Nivel: Avanzado**

Crear tema personalizado responsive.

**Requisitos:**
- Basado en Boost
- Colores personalizables
- Layout moderno
- Mobile-first
- Dark mode

## Proyecto Final: Learning Management Extension

Crear suite completa de plugins que trabajen juntos:

1. **local/lms_core** - Core del sistema
2. **block/lms_dashboard** - Dashboard
3. **mod/lms_lesson** - Lecciones interactivas
4. **local/lms_reports** - Reportes avanzados

**Características:**
- Gamificación
- Progreso visual
- Badges automáticos
- Analytics
- API REST

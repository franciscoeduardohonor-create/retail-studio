# Módulo 2: Manipulación de Datos con dplyr y tidyr 🔧

## Objetivo
Dominar las herramientas fundamentales de tidyverse para manipular y transformar datos de manera eficiente.

## Contenido

### 📝 Lecciones

1. **01_introduccion_dplyr.R** - Operaciones básicas con dplyr
2. **02_filtrar_seleccionar.R** - filter() y select(): extraer datos específicos
3. **03_transformar_datos.R** - mutate(): crear y modificar columnas
4. **04_agrupar_resumir.R** - group_by() y summarise(): análisis agregados
5. **05_unir_datos.R** - Joins: combinar múltiples tablas
6. **06_pivotar_datos.R** - tidyr: reshape de datos (pivot)
7. **07_pipeline_completo.R** - Encadenar operaciones con %>%
8. **08_ejercicios_practicos.R** - Casos de negocio reales

## ⏱️ Tiempo estimado
6-8 horas de estudio y práctica

## 🎯 Al finalizar este módulo podrás:
- Filtrar y seleccionar datos con precisión
- Crear nuevas variables calculadas
- Realizar análisis agregados por grupos
- Combinar múltiples fuentes de datos
- Reestructurar datos (wide ↔ long)
- Encadenar operaciones de manera fluida
- Resolver problemas reales de BI

## 📦 Paquetes necesarios
```r
install.packages("tidyverse")  # Incluye dplyr, tidyr, y más
```

## 💡 Conceptos clave
- **dplyr**: Manipulación de datos (SQL para R)
- **tidyr**: Reestructuración de datos
- **pipe operator** (%>%): Encadenar operaciones
- **tidy data**: Datos organizados y limpios

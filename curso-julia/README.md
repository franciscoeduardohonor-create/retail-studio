¡Bienvenido al curso más completo de Julia en español! Este curso te llevará desde los conceptos básicos hasta técnicas avanzadas de programación en Julia.

## 📚 Sobre Julia

Julia es un lenguaje de programación de alto nivel y alto rendimiento diseñado para computación científica, análisis de datos, y computación numérica. Combina la facilidad de uso de Python con la velocidad de C/C++.

### ¿Por qué aprender Julia?

- **Velocidad**: Rendimiento comparable a C/Fortran
- **Facilidad**: Sintaxis simple y expresiva
- **Multiple Dispatch**: Sistema de tipos poderoso y flexible
- **Ecosistema científico**: Excelente para ciencia de datos, ML, y computación numérica
- **Código abierto**: Comunidad activa y creciente

## 📥 Instalación de Julia

### Linux/Mac:
```bash
wget https://julialang-s3.julialang.org/bin/linux/x64/1.10/julia-1.10.0-linux-x86_64.tar.gz
tar -xvzf julia-1.10.0-linux-x86_64.tar.gz
sudo mv julia-1.10.0 /opt/
sudo ln -s /opt/julia-1.10.0/bin/julia /usr/local/bin/julia
```

### Windows:
Descarga el instalador desde: https://julialang.org/downloads/

### Verificar instalación:
```bash
julia --version
```

## 🛠️ Ejecutando los ejemplos

Todos los archivos `.jl` pueden ejecutarse de dos formas:

**1. REPL de Julia:**
```bash
julia
julia> include("archivo.jl")
```

**2. Desde la terminal:**
```bash
julia archivo.jl
```

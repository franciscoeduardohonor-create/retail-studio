# 🚀 Curso Completo de Vagrant: De Principiante a Avanzado

¡Bienvenido al curso más completo de Vagrant en español! Este curso te llevará desde cero hasta dominar Vagrant con ejemplos prácticos y reales.

   - Tu primera máquina virtual

   - Sincronización de carpetas

### Nivel Intermedio

3. **[Módulo 3: Configuración Intermedia](./modulo-03-configuracion-intermedia/README.md)**
   - Configuración de recursos (CPU, RAM)
   - Variables y condicionales
   - Snapshots y gestión de estados
   - Personalización del entorno

### Nivel Avanzado

## 🎯 Objetivos de Aprendizaje

Al finalizar este curso serás capaz de:

- ✅ Crear y gestionar máquinas virtuales con Vagrant
- ✅ Configurar entornos de desarrollo reproducibles
- ✅ Automatizar el aprovisionamiento de infraestructura
- ✅ Diseñar arquitecturas multi-máquina complejas
- ✅ Integrar Vagrant en pipelines de CI/CD
- ✅ Aplicar mejores prácticas de DevOps

## 📋 Prerrequisitos

- Conocimientos básicos de línea de comandos (terminal/bash)
- Conceptos básicos de virtualización
- Editor de texto (VS Code, Sublime, etc.)
- Ganas de aprender y experimentar

## 💻 Software Necesario

1. **VirtualBox** (o VMware, Hyper-V)
   - Descarga: https://www.virtualbox.org/

2. **Vagrant**
   - Descarga: https://www.vagrantup.com/

3. **Editor de código** (recomendado)
   - VS Code con extensión de Vagrant

## 🚀 Cómo Usar Este Curso

1. **Sigue el orden**: Los módulos están diseñados para construir conocimiento progresivamente
2. **Practica cada ejemplo**: Cada módulo tiene ejemplos que DEBES ejecutar
3. **Experimenta**: Modifica los ejemplos, rompe cosas, aprende
4. **Completa los ejercicios**: Al final de cada módulo hay ejercicios prácticos
5. **Proyectos finales**: Integra todo lo aprendido en proyectos reales

## 📝 Estructura de Cada Módulo

Cada módulo contiene:

- **README.md**: Teoría y explicaciones detalladas
- **ejemplos/**: Código comentado listo para ejecutar
- **ejercicios/**: Desafíos para practicar
- **soluciones/**: Soluciones a los ejercicios

## 🤝 Consejos para el Éxito

1. **No te saltes ejemplos**: Cada uno enseña algo importante
2. **Lee los comentarios**: Los Vagrantfiles están extensamente comentados
3. **Usa la documentación**: https://www.vagrantup.com/docs
4. **Pregunta y experimenta**: La mejor forma de aprender es haciendo

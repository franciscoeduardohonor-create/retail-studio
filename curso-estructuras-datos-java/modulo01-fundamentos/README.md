## 📖 Contenido Teórico

### ¿Qué son las Estructuras de Datos?
Las estructuras de datos son formas de organizar y almacenar información en la memoria para que pueda ser accedida y modificada eficientemente.

### Complejidad Algorítmica (Big O)
- **O(1)** - Constante: El tiempo no depende del tamaño de entrada
- **O(log n)** - Logarítmica: Divide el problema a la mitad cada vez
- **O(n)** - Lineal: Proporcional al tamaño de entrada
- **O(n log n)** - Lineal-logarítmica: Algoritmos de ordenamiento eficientes
- **O(n²)** - Cuadrática: Bucles anidados
- **O(2ⁿ)** - Exponencial: Evitar cuando sea posible

### Arrays en Java
Un array es una colección de elementos del mismo tipo almacenados en posiciones contiguas de memoria.

**Ventajas:**
- Acceso rápido por índice: O(1)
- Eficiente en memoria
- Fácil de usar

**Desventajas:**
- Tamaño fijo
- Inserción y eliminación costosas: O(n)
- Desperdicio de memoria si no se usa completamente

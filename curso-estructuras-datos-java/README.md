# 🎓 Curso Práctico de Estructuras de Datos en Java

## 📘 Descripción del Curso

Bienvenido al curso completo de **Estructuras de Datos en Java**, diseñado para llevarte desde principiante hasta nivel avanzado. Este curso combina teoría, ejemplos prácticos comentados y ejercicios que podrás resolver por ti mismo.

### ¿Qué Aprenderás?

- Estructuras de datos fundamentales y avanzadas
- Análisis de complejidad algorítmica (Big O)
- Implementación desde cero de estructuras de datos
- Técnicas y patrones de programación
- Resolución de problemas comunes en entrevistas técnicas

## 🎯 Objetivos del Curso

✅ **Entender** cómo funcionan internamente las estructuras de datos
✅ **Implementar** tus propias versiones desde cero
✅ **Analizar** la eficiencia de algoritmos (complejidad temporal y espacial)
✅ **Aplicar** las estructuras correctas para cada problema
✅ **Prepararte** para entrevistas técnicas

## 📊 Complejidad Algorítmica - Guía Rápida

| Notación | Nombre | Ejemplo |
|----------|--------|---------|
| O(1) | Constante | Acceso a array por índice |
| O(log n) | Logarítmica | Búsqueda binaria |
| O(n) | Lineal | Recorrer un array |
| O(n log n) | Lineal-log | Merge Sort, Quick Sort |
| O(n²) | Cuadrática | Bubble Sort, bucles anidados |
| O(2ⁿ) | Exponencial | Fibonacci recursivo |

**Regla de oro:** Siempre busca la solución más eficiente posible.

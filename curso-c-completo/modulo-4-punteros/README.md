# Módulo 4: Punteros y Memoria Dinámica

## Objetivos de Aprendizaje
- Entender qué son los punteros y cómo usarlos
- Trabajar con direcciones de memoria
- Usar memoria dinámica (malloc, calloc, free)
- Comprender punteros y arrays
- Implementar paso por referencia en funciones

## Contenido

### 1. Fundamentos de Punteros
- Declaración y operadores (* y &)
- Punteros y variables
- Aritmética de punteros
- Punteros NULL

### 2. Punteros y Arrays
- Relación entre punteros y arrays
- Recorrer arrays con punteros
- Arrays de punteros

### 3. Memoria Dinámica
- malloc() - reservar memoria
- calloc() - reservar e inicializar
- realloc() - redimensionar
- free() - liberar memoria

### 4. Punteros y Funciones
- Paso por referencia
- Retornar múltiples valores
- Punteros a funciones

2. **punteros_arrays.c** - Punteros y arrays
3. **memoria_dinamica.c** - malloc, calloc, free
4. **paso_por_referencia.c** - Funciones con punteros

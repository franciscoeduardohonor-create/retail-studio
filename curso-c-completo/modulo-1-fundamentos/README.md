# Módulo 1: Fundamentos Básicos de C

## Objetivos de Aprendizaje
- Entender la estructura básica de un programa en C
- Aprender sobre tipos de datos y variables
- Dominar la entrada/salida básica
- Comprender operadores aritméticos y lógicos

## Contenido

### 1. Estructura Básica de un Programa
### 2. Variables y Tipos de Datos
### 3. Entrada y Salida (printf/scanf)
### 4. Operadores
### 5. Conversiones de Tipo

## Ejemplos Disponibles

1. **hola_mundo.c** - Tu primer programa en C
2. **variables.c** - Declaración y uso de variables
3. **tipos_datos.c** - Todos los tipos de datos básicos
4. **entrada_salida.c** - Leer y escribir datos
5. **operadores.c** - Operadores aritméticos, lógicos y relacionales
6. **calculadora_simple.c** - Proyecto práctico: calculadora

## Ejercicios para Practicar

Todos los ejercicios están en la carpeta `ejercicios/` con instrucciones detalladas.

## Cómo Compilar y Ejecutar

```bash
# Compilar
gcc nombre_archivo.c -o nombre_programa

# Ejecutar
./nombre_programa
```

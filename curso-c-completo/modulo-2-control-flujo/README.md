# Módulo 2: Control de Flujo y Funciones

## Objetivos de Aprendizaje
- Dominar estructuras condicionales (if, else, switch)
- Aprender bucles (for, while, do-while)
- Entender y crear funciones
- Manejar el alcance de variables
- Implementar recursividad básica

## Contenido

### 1. Estructuras Condicionales
- if, else if, else
- Operador ternario
- switch/case

### 2. Bucles (Loops)
- while
- do-while
- for
- break y continue
- Bucles anidados

### 3. Funciones
- Declaración y definición
- Parámetros y retorno
- Prototipos de funciones
- Recursividad

## Ejemplos Disponibles

1. **if_else.c** - Estructuras condicionales
2. **switch_case.c** - Switch para múltiples opciones
3. **while_loop.c** - Bucle while
4. **do_while_loop.c** - Bucle do-while
5. **for_loop.c** - Bucle for
6. **break_continue.c** - Control de bucles
7. **funciones_basicas.c** - Crear y usar funciones
8. **funciones_avanzadas.c** - Funciones con parámetros y retorno
9. **recursividad.c** - Funciones recursivas
10. **menu_interactivo.c** - Proyecto práctico completo

## Ejercicios para Practicar

Todos los ejercicios están en la carpeta `ejercicios/` con instrucciones detalladas.

## Prerequisitos

Debes haber completado el Módulo 1 y sentirte cómodo con:
- Variables y tipos de datos
- Operadores
- Entrada/salida básica

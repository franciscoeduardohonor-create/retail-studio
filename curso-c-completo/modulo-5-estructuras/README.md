# Módulo 5: Estructuras y Tipos de Datos Avanzados

## Objetivos de Aprendizaje
- Crear y usar estructuras (struct)
- Trabajar con uniones (union)
- Usar enumeraciones (enum)
- Definir tipos personalizados con typedef
- Implementar arrays de estructuras

## Contenido

### 1. Estructuras (struct)
- Declaración y definición
- Acceso a miembros
- Estructuras anidadas
- Punteros a estructuras

### 2. Uniones (union)
- Diferencia con struct
- Uso de memoria
- Casos de uso

### 3. Enumeraciones (enum)
- Crear constantes nombradas
- Uso en switch

### 4. typedef
- Crear alias de tipos
- Simplificar código

# Módulo 3: Arrays y Strings

## Objetivos de Aprendizaje
- Trabajar con arrays unidimensionales y multidimensionales
- Manipular cadenas de texto (strings)
- Usar funciones de la biblioteca string.h
- Implementar algoritmos de búsqueda y ordenamiento básicos

## Contenido

### 1. Arrays
- Declaración e inicialización
- Acceso a elementos
- Arrays multidimensionales
- Pasar arrays a funciones

### 2. Strings (Cadenas)
- Strings como arrays de char
- Funciones de string.h (strlen, strcpy, strcmp, etc.)
- Entrada/salida de strings
- Manipulación de strings

### 3. Algoritmos Básicos
- Búsqueda lineal
- Ordenamiento burbuja
- Inversión de arrays

5. **proyecto_agenda.c** - Proyecto práctico con arrays y strings

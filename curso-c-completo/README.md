# Curso Completo de C: De Principiante a Avanzado

¡Bienvenido al curso más completo de programación en C! Este curso te llevará desde los conceptos más básicos hasta temas avanzados, con ejemplos prácticos y ejercicios para cada módulo.

## 📋 Descripción del Curso

Este curso está diseñado para:
- **Principiantes** que nunca han programado
- **Programadores** que quieren aprender C
- **Estudiantes** que necesitan reforzar sus conocimientos
- **Desarrolladores** que buscan dominar C

## 🎯 Objetivos del Curso

Al completar este curso, serás capaz de:
- ✅ Escribir programas en C desde cero
- ✅ Entender conceptos fundamentales de programación
- ✅ Trabajar con punteros y memoria dinámica
- ✅ Manipular archivos y estructuras de datos
- ✅ Crear aplicaciones robustas y eficientes
- ✅ Aplicar buenas prácticas de programación

## 🚀 Cómo Usar Este Curso

### 1. Requisitos Previos

**Software necesario:**
- Compilador de C (GCC recomendado)
  - **Linux/Mac:** Ya viene instalado o `sudo apt-get install gcc`
  - **Windows:** MinGW o usar WSL

**Verificar instalación:**
```bash
gcc --version
```

### 2. Metodología de Estudio

**Paso a paso:**

1. **Lee el README del módulo**
   - Entiende los objetivos
   - Revisa el contenido

2. **Estudia los ejemplos en orden**
   - Abre cada archivo .c
   - Lee todos los comentarios
   - Entiende cada línea

3. **Compila y ejecuta**
   ```bash
   gcc nombre_archivo.c -o programa
   ./programa
   ```

4. **Experimenta**
   - Modifica el código
   - Prueba diferentes valores
   - Rompe cosas y arréglelas

5. **Resuelve ejercicios**
   - Intenta resolverlos sin ver soluciones
   - Compara tu solución con la oficial

6. **Crea tus propios proyectos**
   - Aplica lo aprendido
   - Combina conceptos

### 3. Tiempo Estimado

- **Total del curso:** 15-20 semanas
- **Estudio recomendado:** 5-10 horas por semana
- **Práctica:** ¡La más que puedas!

### 4. Consejos de Aprendizaje

✅ **HAZ:**
- Escribe código a mano (no solo copiar/pegar)
- Comenta tu código
- Experimenta y comete errores
- Practica todos los días (aunque sea 30 min)
- Busca ayuda cuando te atasques

❌ **NO HAGAS:**
- Saltar módulos
- Solo leer sin programar
- Darte por vencido cuando algo no funcione
- Copiar código sin entenderlo
- Ir demasiado rápido

## 📖 Compilar y Ejecutar Programas

### Comandos Básicos

**Compilar:**
```bash
gcc archivo.c -o programa
```

**Ejecutar:**
```bash
./programa          # Linux/Mac
programa.exe        # Windows
```

**Compilar con warnings:**
```bash
gcc -Wall -Wextra archivo.c -o programa
```

**Compilar con debugging:**
```bash
gcc -g archivo.c -o programa
gdb ./programa
```

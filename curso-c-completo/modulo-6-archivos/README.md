# Módulo 6: Manejo de Archivos

## Objetivos de Aprendizaje
- Abrir y cerrar archivos
- Leer y escribir archivos de texto
- Trabajar con archivos binarios
- Posicionamiento en archivos
- Manejo de errores

## Contenido

### 1. Archivos de Texto
- fopen, fclose
- fprintf, fscanf
- fgets, fputs
- Modos de apertura

### 2. Archivos Binarios
- fread, fwrite
- Guardar estructuras
- Diferencia con archivos de texto

### 3. Posicionamiento
- fseek, ftell, rewind
- Acceso aleatorio

## Ejemplos Disponibles

1. **archivos_texto.c** - Leer/escribir texto
2. **archivos_binarios.c** - Archivos binarios
3. **proyecto_registro.c** - Sistema de archivos completo
